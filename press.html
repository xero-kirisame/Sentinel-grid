About Sentinel Grid (for press use)

"Sentinel Grid is a virtual stock trading simulator for the Indian National Stock Exchange (NSE). Built for aspiring investors who want to learn before they risk real capital, Sentinel Grid provides realistic, live-simulated prices for 25+ NSE-listed companies, a full trading interface with market, limit, and stop-loss orders, and a portfolio analytics dashboard — all completely free. Sentinel Grid is available as a web application optimised for mobile and desktop, and is not a regulated financial service. No real money is involved."
